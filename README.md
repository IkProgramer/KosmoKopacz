# KosmoKopacz

Automatic mining mod for Minecraft.

Type /kk to open the menu and configure everything to your liking.

## Modules

- **Miner** — holds the left mouse button and mines for you (default key: O)
- **Tool Protection** — switches tools or stops mining before the tool breaks
- **AutoRepair** — automatically uses /repair when your tool is about to break
- **Drop Items** — periodically drops selected items
- **Walker** — walks in circles around an area you set
